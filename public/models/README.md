# Subaru 2002 3D asset

The model is **not included** because automated downloading and redistribution rights could not be verified.

1. Visit https://sketchfab.com/3d-models/2002-subaru-impreza-wrx-sti-extreme-e84cf42740db4624b50f47fab26c9dfc
2. Confirm the author offers an authorized download and review the license. If downloads are disabled, obtain permission or choose a different model.
3. Download the model, convert to GLB with Blender if needed, and place it here as **subaru-2002.glb**.
4. Run the app. It will replace the procedural car automatically; the four propulsors remain attached to the simulation body.
5. Adjust forward-axis alignment / dimensions in `src/visuals.ts` for your export. The GLB is visual only and does not alter physics.

For public redistribution, follow the actual model license and attribution requirements. Don't commit the asset if redistribution is not authorized.
